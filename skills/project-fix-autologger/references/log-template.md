# 中文修复记录模板

每条记录必须以时间戳开头：

`[YYYY-MM-DD HH:MM:SS]`

建议结构：

## [YYYY-MM-DD HH:MM:SS] <修复标题>

- 时间戳: `<YYYY-MM-DD HH:MM:SS>`
- 问题编号: `<例如 20260422_170000>`
- 状态: `<待修复 或 已修复>`
- 问题现象: <什么地方出现了什么问题>
- 根因分析: <为什么会出现>
- 修改方法: <具体怎么改>
- 修复结果: <改完后的效果>
- 验证方式: <测试命令/人工复核与结果>
- 涉及文件: `<逗号分隔文件列表>`
- 视频文件: `<绝对路径或项目相对路径>`
- 问题时间点: `<例如 00:03:25>`
- 裁剪区间: `<例如 00:03:20-00:03:40>`
- 视频问题详情: <该时间点的具体问题>
- 标签: `<可选，中文标签>`

建议流程：

1. 发现 bug 后先写一条 `待修复`
2. 修复完成后，再用同一个“问题编号”写一条 `已修复`
